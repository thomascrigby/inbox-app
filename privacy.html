Privacy Policy

Inbox · Last updated October 7, 2026

Inbox is a personal app used only by its author. It is not offered to anyone else.

What it accesses

With the user's permission, Inbox uses Google APIs to read, send, and organize the user's Gmail (archive, trash, spam, read/unread, drafts), and to read the user's Google contacts so it can suggest email recipients.

Where data goes

Email and contact data is processed on the user's own computer. A copy of recent mail and contacts is stored on that computer so the app works offline. Inbox has no server of its own, and it does not sell, share, or transfer Google user data to anyone.

When the user explicitly asks the app's built-in assistant for help (for example, to draft a reply), the relevant email text is sent to Anthropic's Claude API to produce that response. Nothing is sent automatically.

Google API Services

Inbox's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not used for advertising or to train AI models.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's folder removes every local copy.
